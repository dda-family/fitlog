# PRODUCT_SPEC.md — Fitlog 제품/기능 정의서

> 사전 개발 검토 결정 반영본. 변경 요약은 `docs/DECISIONS.md`.

## 1. 제품 목적
Fitlog는 개인 운동 기록용 웹앱이다.

목표는 다음 네 가지다.

1. 헬스장에서 오늘 해야 할 운동을 바로 확인한다.
2. 실제 수행 중량·반복수·세트를 빠르게 기록한다.
3. 현재 가이드 대비 부족/적정/증량 후보를 확인한다.
4. 기록을 기반으로 ChatGPT/Claude와 루틴을 조정하고, 사용자가 승인한 새 가이드를 다시 앱에 반영한다.

## 2. 사용자와 사용 조건
- 사용자: 1명 (다른 사람은 각자 앱을 설치해 독립 사용 가능. 데이터 공유는 없음)
- 운동 경력: 현재 약 2개월 (초보)
- 주 3회 루틴 (기본 화 / 목 / 토, 요일 변경 가능)
- 주 운동 시간대: 약 21:00~22:30, 1회 약 90분
- 웨이트 후 경사 걷기: 기본 30분
- iPhone 무음 모드 + AirPods 착용
- 운동 중 앱을 직접 터치해 기록
- 로그인/클라우드 불필요, 기록은 iPhone 로컬 저장

## 3. 제품 핵심 개념

### 3.1 루틴 템플릿 (Routine Template) ★신규
'하루치 운동 묶음'이다. 요일에 종속되지 않는 독립 엔티티.

- 이름 (예: "등·어깨·이두")
- 순서
- 그 템플릿에 속한 운동들의 가이드 목록

기본 3개 템플릿이 시드로 제공되지만, 사용자는 템플릿을 추가/삭제/이름변경할 수 있다(4분할 확장 등).

### 3.2 요일 매핑 (Day Mapping) ★신규
`요일 → 템플릿` 연결이다. 기본값:

```text
화 → 등·어깨·이두
목 → 가슴·삼두
토 → 하체
그 외 요일 → 없음
```

- 오늘 화면은 오늘 요일의 매핑을 보고 템플릿을 **제안**한다.
- 사용자는 언제든 다른 템플릿을 직접 선택할 수 있다. (화 루틴을 수요일에 수행 가능)
- 매핑은 설정/가이드 화면에서 변경 가능(화목토 → 월수금 등).

### 3.3 Guide
'해야 할 것'이다. 각 템플릿 안에서 운동별 현재 권장값:
- 운동명 / 중량(미정 허용) / 목표 세트 / 최소 반복 / 최대 반복 / 선택 여부 / 순서 / 워밍업 사용 여부 / 메모

### 3.4 Actual
'실제로 한 것'이다. 각 세트의 실제 중량·반복수, 완료 여부, 생략 여부, 세트 종류(본세트/워밍업).

### 3.5 Evaluation
Guide와 Actual을 비교해 단순 판정한다. 참고용이며 자동으로 가이드를 변경하지 않는다.

### 3.6 History
날짜별 실제 기록과 과거 가이드 변경 이력을 보존한다. **세션은 실제 캘린더 날짜·요일·수행 템플릿을 항상 함께 기록**한다.

## 4. MVP 메뉴
하단 네비게이션(최대 5개):

```text
오늘 | 기록 | 가이드 | AI 코치 | 설정
```

## 5. 현재 기본 운동 가이드 (시드)
앱 최초 설치 시 기본값. 이후 직접 수정 가능. 중량이 "미정"인 항목은 시드에서 비워두고(§Data `null`), 첫 사용값을 자동 채움한 뒤 사용자가 원터치로 가이드에 승격할 수 있다.

기본 요일 매핑: 화=템플릿1, 목=템플릿2, 토=템플릿3.

### 5.4 공통 유산소
- 트레드밀 경사 걷기 / 경사 12 / 속도 4.8km/h / 목표 30분
- MVP 기본값에서 40분으로 자동 확대하지 않는다.

## 6. 세트 기록 기능
각 운동 카드에서:
- 현재 가이드 중량 표시 / 지난번 기록 표시
- 오늘 실제 중량 입력·수정 (기본값은 가이드값 자동 채움. 가이드가 미정이면 **지난 사용값** 자동 채움)
- 각 세트 반복수 입력 / 세트 완료 / 세트 삭제·수정
- 워밍업 사용 종목은 본세트와 구분된 워밍업 입력 제공(§7, §8)
- 운동 전체 생략 / 운동 완료

### 6.1 미정 중량 처리
- 시드 가이드 중량이 `null`인 종목은 첫 기록 시 입력값을 그 종목의 "지난 사용값"으로 기억한다(세션 기록에서 파생).
- 다음 사용부터 그 값을 입력칸에 자동 채움한다.
- 운동 카드/가이드 화면에 **"이 값을 가이드 기본값으로 저장"** 원터치 버튼을 제공한다. 누르면 정식 `targetWeight`로 승격되고 `guideHistory`에 `manual` 이력으로 남는다. **자동 승격은 하지 않는다.**

### 6.2 최소 터치 원칙
반복수·중량은 +/- 버튼 우선, 숫자 직접 탭 시 키패드 입력 허용. 버튼은 오작동하지 않을 만큼 크게.

## 7. 휴식 타이머 (사전 검토 반영)

### 7.1 세트 간 휴식
- 기본 90초. 세트 완료 버튼을 누르면 시작(자동 감지 금지).
- 시작과 동시에 화면 유지(§CLAUDE §5.2)가 켜진다.
- 0초가 되면 자체 차임 재생, 타이머 종료. 다음 세트는 사용자가 직접 시작.

### 7.2 운동 간 휴식/세팅
- 기본 180초. 해당 운동 마지막 세트 완료 후 `운동 완료 · 다음 운동 준비` 버튼으로 시작.
- 0초에 동일 차임. 자동으로 다음 운동을 시작하지 않는다.

### 7.3 사운드/화면
- 진동 없음. 휴식 종료는 **자체 제작 차임**(`assets/sounds/rest-end.mp3`). iPhone 기본 알림음은 웹앱에서 사용 불가.
- 알림음은 앱이 **화면 켜진 포그라운드**일 때 확실히 재생된다. 타이머가 도는 동안 화면을 깨워둔다.
- 폰을 잠그거나 다른 앱으로 나가면 0초 알림음은 보장되지 않는다. 대신 상단에 큰 카운트다운을 고정 표시해 눈으로 확인 가능하게 한다.
- `🎧 알림 테스트` 버튼 필수(오디오 언락 겸용).

## 8. 수행 판정 규칙
판정은 최대한 단순하고 설명 가능해야 한다. **본세트(`work`)만 판정에 사용**하고 워밍업(`warmup`) 세트는 제외한다.

### 8.1 세트 판정
- 실제 반복수 < 최소: `부족`
- 최소 ≤ 실제 ≤ 최대: `적정`
- 실제 > 최대: `상한 초과`

### 8.2 운동 판정
- 완료 본세트 수 < 목표 세트 수: `볼륨 부족`
- 목표 세트 모두 완료 + 모든 세트 최소 이상: `완료`
- 목표 세트 모두 완료 + 모든 세트 최대 도달: `증량 후보`
- 사용자가 생략: `미실시`
- 시작 안 함: `미시작`

`증량 후보`는 알림일 뿐 자동 증량하지 않는다.

### 8.3 어시스트 종목 역방향 ★
`sideMode: assist` 종목(어시스트 딥스/풀업)은 판정 임계값은 동일하지만, `증량 후보`의 **권장 방향이 반대**다.
- 일반 종목: 증량 후보 → "중량 ↑ 고려"
- 어시스트 종목: 증량 후보 → **"보조중량 ↓ 고려(난이도 ↑)"**
- 판정 결과에 `progressionDirection`(`increase` / `decrease_assist`)를 함께 표기해 문구를 올바르게 노출한다.

### 8.4 미정 중량 종목
가이드 중량이 `null`이면 중량 기반 기대치는 건너뛰고, 실제 중량이 입력된 뒤 반복수 기준으로만 세트 판정한다.

### 8.5 선택 운동
선택 운동은 생략해도 전체 완료율을 깎지 않는다.

## 9. 미실시/부족 사유
운동/세트 생략 시 선택적으로 사유 기록. 초기 선택지: 시간 부족 / 힘 부족 / 통증·불편 / 기구 사용 중 / 의도적 생략 / 기타. 입력 강제하지 않음.

## 10. 전체 루틴 완료율
필수 운동만 기본 분모. `완료`·`증량 후보`는 완료로 계산. `볼륨 부족`은 부분 완료로 별도 표시. 선택 운동 생략은 완료율에 영향 없음.

## 11. 기록 화면
날짜별 조회. 최소 표시: 날짜 · **요일** · 수행 템플릿명 · 운동별 실제 세트/중량/반복 · 유산소 · 완료/부족/미실시 상태. 추가 가능: 주간 총 세트, 부위별 목표 대비 실제 세트, 유산소 총 시간, 증량 후보 목록. 복잡한 차트는 MVP 필수 아님.

## 12. 가이드/커스터마이징 화면
사용자가 현재 루틴을 직접 편집할 수 있다.

### 12.1 운동 단위 편집
운동 순서 · 운동명 · 필수/선택 · 중량 · 목표 세트 · 최소/최대 반복 · **워밍업 사용 여부** · 메모. 가이드 수정 시 기존 기록은 변경하지 않는다.

### 12.2 템플릿/요일 편집 ★신규
- 템플릿 추가 / 삭제 / 이름 변경 / 순서 변경
- 템플릿에 운동 추가 / 제거
- `요일 → 템플릿` 매핑 변경 (예: 화목토 → 월수금, 또는 4분할)

이 편집은 계획(가이드)에만 영향을 준다. 이미 저장된 세션 기록의 날짜·요일·수행 내용은 불변이다.

## 13. AI 코치 (MVP: API 미호출)
### 13.1 Export — `AI 분석용 프롬프트 만들기`
포함: 현재 템플릿/요일 매핑, 현재 가이드, 최근 4주 실제 수행, 운동별 최근 기록, 미실시/부족 사유, 주간 완료율, 증량 후보, 사용자 제약(주3회·회당 약 90분·유산소 30분·데드리프트 제외). 사용자가 복사해 ChatGPT/Claude에 붙여넣는다.

### 13.2 Import
AI가 반환한 정해진 JSON을 붙여넣으면 앱이: 유효성 검사 → 현재 가이드와 비교 → 변경점 표시 → 사용자가 적용 항목 선택 → 승인 후 반영 → 이전 가이드를 히스토리에 저장. **자동 적용하지 않는다.**

## 14. 백업
설정 화면에 `운동기록 백업`(JSON export) / `백업 복원`(import) / `전체 데이터 초기화`(강한 확인). 백업엔 전체 기록·가이드·템플릿·요일 매핑·설정·가이드 이력 포함. 복원은 검증 후 덮어쓰기(실패 시 기존 데이터 유지).

## 15. 비기능 요구사항
iPhone 세로 우선 / 명확한 대비 / 큰 터치 영역 / 오프라인 / 빠른 시작 / 새로고침 후 기록 유지 / 실수 이동 시 진행 기록 최대 유지 / 의도치 않은 삭제 금지. iOS가 미사용 PWA 저장소를 비울 수 있으므로 주기적 JSON 백업을 권장(설정 안내 문구 포함).

## 16. MVP 성공 기준
1. 화요일 헬스장에서 Fitlog 실행 → 오늘 템플릿 확인
2. 랫풀다운 28kg 12회 → 반복 입력 → 완료 버튼 1회
3. 90초 타이머 시작 + 화면 유지 → 0초에 AirPods로 차임
4. 다음 세트 반복 → 마지막 세트 후 180초 타이머
