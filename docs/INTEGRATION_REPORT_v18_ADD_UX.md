# Fitlog 운동 추가·편집 UX 개편 — 완료 보고 (SW fitlog-v18)

운동 종목을 추가/편집하는 흐름을 사용자 관점으로 재설계했다. 근육 매핑을 사용자가 직접 만지는 UI를 없애고,
기본 제공 운동은 운동 ID로 매핑이 자동 연결되도록 했다. 기존 운동 기록·가이드·히트맵·3D·IndexedDB·백업 포맷은 변경하지 않았다.

## 1. 변경/추가 파일

| 파일 | 구분 | 수정 목적 |
|---|---|---|
| `src/catalog-data.js` | 수정(가산) | 로컬 검색용 `SEARCH_KEYWORDS`(79종 한글 동작·부위·기구 키워드) 추가. 기존 `CATALOG`/`MUSCLE_MAP`은 무변경. |
| `src/app.js` | 수정 | 운동 추가 진입 화면(운동 목록 선택/찾아보기/직접 만들기) + 검색·중복방지·자동매핑 로직. 편집 화면 근육 매핑 UI 제거·읽기전용 부위 표시. |
| `src/styles.css` | 수정(가산) | `.addex-*`(추가 플로우), `.gedit-parts`(읽기전용 부위) 스타일. 기존 클래스 무변경. |
| `service-worker.js` | 수정 | `CACHE_VERSION` v17→v18(셸 갱신 트리거). 캐시 목록·로직 무변경. |

## 2. 운동 추가 UX 변경

- **진입 화면**: `+ 운동 추가` → ① 자주 하는 운동(최근 기록 빈도, 없으면 숨김) ② 운동 목록 선택 ③ 운동 찾아보기 ④ 직접 운동 만들기.
  - 근력/유산소 버튼 2개를 단일 진입점으로 통합. "카탈로그" 같은 개발 용어는 사용자 화면에 노출하지 않음(내부 변수만).
- **운동 목록 선택**: 이름 검색 + 필터(전체·근력·유산소·부위). 각 항목 `＋` 즉시 추가, 이미 있으면 `이미 추가됨`.
- **운동 찾아보기**: 이름·별칭·부위·기구 + **동작 설명** 로컬 검색(점수순, 모호하면 후보 다수). 상세 화면(주요 부위·설명, 향후 3D 미리보기 연결 지점). 외부 AI/서버 미사용.
- **직접 운동 만들기**: 이름·유형·기본 가이드 + 동작 설명(선택). 근육 매핑 요구 없음. 이름이 기존 운동과 유사하면 "이미 준비된 운동" 안내(강제 대체 안 함).

## 3. 운동 편집 UX 변경

- 근육 매핑 직접 설정 버튼(`🎯 근육 매핑 설정`) 제거. `openMuscleMapModal` 함수·`userMuscleMap` 데이터는 향후 AI JSON 적용용으로 보존.
- 대신 **주요 운동 부위 읽기 전용 표시**(운동 종목에서 자동 도출). 매핑 없는 운동은 "근육 히트맵 집계에서 제외" 안내.
- 목표 중량·세트·반복·선택 운동·워밍업·순서·삭제 등 기존 기능 그대로.

## 4. 근육 매핑 자동화 처리 방식

- 매핑 조회 순서(기존 `heatmap.effectiveCatalogId` 그대로): **사용자매핑 > 운동.catalogId > EXISTING_LINK > 없으면 히트맵 제외.**
- 기본 제공 운동을 추가하면 앱 운동에 `catalogId`가 붙어 근육 매핑이 자동 연결된다. 사용자는 매핑을 만지지 않는다.
- 이 로직은 **신규 개발이 아니라 기존 배관을 노출·정리한 것**이라 히트맵 계산부는 무변경.

## 5. 사용자 지정 운동 처리 방식

- **같은 운동은 하나로 재사용**: 카탈로그 운동 추가 시 카탈로그 ID를 앱 운동 ID로 재사용. 시드 17종은 `EXISTING_LINK` 역방향으로 인식(예: 카탈로그 `barbell_bench_press` → 기존 `bench-press` 재사용) → 중복·매핑 꼬임 방지.
- **직접 만든 운동**: `ex-<timestamp>` ID, `category:"custom"`. 매핑 없으면 히트맵에서만 제외되고 가이드·기록은 정상. `description`(선택) 저장 → 향후 AI 매핑에 활용.

## 6. 기존 데이터 영향 — 없음(보존)

- IndexedDB 스키마·스토어·시드·백업 포맷 변경 없음. 새 스토어 없음.
- 기존 가이드·운동·기록·사용자 지정 매핑 그대로 유지. 운동 ID/이름 일괄 변경 없음.
- 기존 3D 인체 히트맵·유산소 별도 집계 정책 무변경.

## 7. 실행한 테스트 (이 환경 실제 실행)
