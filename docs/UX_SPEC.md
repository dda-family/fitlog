# UX_SPEC.md — Fitlog 화면/사용 흐름 정의서

> 사전 개발 검토 결정 반영본. 변경 요약은 `docs/DECISIONS.md`.

## 1. UX 목표
'운동 기록 앱을 쓰는 느낌'보다 '운동 중 필요한 숫자만 빠르게 확인하고 누르는 도구'에 가깝게.

핵심 원칙: 한 손 조작 / 큰 버튼 / 짧은 문구 / 화면 전환 최소화 / 한 화면에서 현재 운동과 타이머 동시 확인 / 키보드 최소 / 디자인보다 정보 우선순위.

## 2. 네비게이션
하단 고정: `오늘 | 기록 | 가이드 | AI 코치 | 설정`. 운동 중에는 `오늘`이 중심.

## 3. 앱 최초 실행
긴 온보딩 없음.

```text
Fitlog
개인 운동기록
[시작하기]
```

시작하면 기본 3개 템플릿 + 기본 요일 매핑(화·목·토)이 로드된다. 설정/가이드에서 언제든 변경.

## 4. 오늘 화면

### 4.1 상단
오늘 요일 매핑에 템플릿이 있으면 제안:

```text
Fitlog
8월 29일 (토)

오늘 추천: 하체
[운동 시작]   [다른 템플릿 선택 ▾]
```

- 오늘 요일에 매핑이 없거나(예: 수요일) 사용자가 원하면 `다른 템플릿 선택`으로 어떤 템플릿이든 고를 수 있다.
- 화요일 템플릿을 수요일에 골라 시작해도, 저장되는 세션은 **실제 날짜(수)** 기준.
- 자동으로 가장 가까운 루틴을 강제하지 않는다.

### 4.2 운동 중 상단 고정 타이머
휴식 타이머가 동작할 때만 표시(스크롤해도 보임):

```text
⏱ 휴식 00:47
```

종료 시 짧게 `✓ 휴식 종료` 표시 후 사라져도 된다. **타이머 동작 중에는 화면이 꺼지지 않는다**(내부적으로 무음 video로 화면 유지).

## 5. 운동 카드

예: 랫풀다운

```text
랫풀다운

가이드    28kg · 8~12회 · 3세트
지난번    28kg · 12 / 11 / 9

오늘
1세트  [ − ] 28 kg [ + ]   [ − ] 12 회 [ + ]   [ ✓ 세트 완료 ]
2세트  28 kg                 − 회
3세트  28 kg                 − 회

[이번 운동 생략]
```

정보 우선순위: ① 운동명 ② 현재 가이드 ③ 입력 중인 세트 ④ 완료 버튼. 지난번 기록은 보조.

### 5.1 미정 중량 카드
가이드가 미정인 종목(이두 컬 등):

```text
이두 컬
가이드    중량 미정 · 10~15회 · 2세트
지난번    (없음)

오늘
1세트  [ − ]  ?  kg [ + ]   ...
```

- 첫 기록 후에는 `지난번` 값이 채워지고, 다음부터 입력칸에 자동 채움.
- 카드에 `⤴ 이 값을 가이드 기본값으로 저장` 버튼 노출(누르면 가이드 확정, 자동 아님).

### 5.2 워밍업 종목 카드 (벤치·스쿼트)
본세트 위에 접이식 워밍업 영역:

```text
벤치프레스
가이드    총 40kg · 8~10회 · 3세트

워밍업 (판정 제외)  ▾
  · 빈 봉 20kg × 10~12
  · 30kg × 5~8
  [워밍업 세트 기록 +]

본세트
1세트  [ − ] 40 kg [ + ]  [ − ] 8 회 [ + ]  [ ✓ 세트 완료 ]
...
```

- 워밍업 세트 기록은 선택. 완료율·증량후보 판정에 들어가지 않으며 시각적으로 흐리게 구분.
- 워밍업이 UI를 복잡하게 만들면 접힌 상태를 기본으로.

## 6. 숫자 입력
기본값 자동 채움(가이드값, 미정이면 지난 사용값) / 중량·반복 +/- 버튼 / 직접 탭 시 키패드. 버튼은 크게.

## 7. 세트 완료 흐름

```text
반복수 입력 → [✓ 세트 완료] → 세트 저장 + 90초 타이머 시작(+화면 유지)
→ 00:00 → 짧은 차임 → 타이머 종료(화면 유지 해제)
```

- 완료 버튼 1회로 저장 + 타이머 시작.
- 타이머 종료 후 자동 액션 없음. 다음 세트는 사용자가 직접 시작.

## 8. 마지막 세트 흐름
마지막 목표 세트의 버튼 라벨 자체를 `✓ 운동 완료 · 다음 운동 준비`로 바꾼다. 이 버튼이 마지막 세트 저장 + 180초 타이머 시작을 수행. 90초와 180초가 동시에 시작되면 안 된다.

## 9. 타이머 표시/제어 (start-and-forget)
사용자 흐름: 세트 수행 → 폰 들어 기록 → 타이머 시작 탭 → 폰 내려놓고 휴식 → AirPods에서 한 번 울림 → 다시 운동. 이 루프가 반복된다.

- 표시: 인라인(현재 카드) + 상단 고정, 둘 다 카운트다운.
- **제어 버튼 없음.** 일시정지·정지(끄기) 버튼을 두지 않는다. 시작하면 0초까지 자동으로 흐른다.
- 실행 중 타이머는 다음 `세트 완료`/`운동 완료`를 누르면 새 타이머로 자연 대체된다(별도 정지 불필요).
- 종료 알림: 진동 없음 / **0초에 짧은 차임 단 한 번**(반복·재알림 없음) / 운동 시작 전 `🎧 알림 테스트` 제공.
- 타이머는 `endsAt` 기준. 앱 복귀 시 남은 시간 재계산해 표시 보정.

## 10. 운동 생략
카드의 보조 액션 `[이번 운동 생략]` → 선택적 사유(시간 부족 / 힘 부족 / 통증·불편 / 기구 사용 중 / 의도적 생략 / 기타 / 사유 없이 생략). 사유 화면은 빠르게 닫힘.

## 11. 세트 부족 종료
목표 3세트 중 2세트만 하고 넘어갈 수 있어야 한다.

```text
2/3세트 완료
[운동 종료]
```

앱은 막지 않고 기록에 `볼륨 부족`으로 저장.

## 12. 운동 순서
기본 순서를 표시하되 강제하지 않는다. 자유롭게 다른 카드로 스크롤/탭 가능(기구 사용 중 현실 고려).

## 13. 오늘 운동 종료

```text
오늘 웨이트 종료
완료 5 · 부분 완료 1 · 미실시 1
[유산소 기록]  [오늘 운동 저장]
```

시간 자동 측정은 필수 아님.

## 14. 유산소 입력
기본값 자동 채움(경사 12 / 4.8km/h / 30분), 사용자가 변경 가능. `[저장]`.

## 15. 기록 화면

### 날짜 목록 (요일·템플릿 표시)
```text
8/29 토  하체        완료
8/27 목  가슴/삼두   부분완료
8/26 수  등/어깨/이두 완료      ← 화 템플릿을 수요일에 수행한 예
8/25 화  등/어깨/이두 완료
```

### 세부 기록
```text
랫풀다운
가이드 28kg · 8~12 × 3
실제   28kg · 12 / 11 / 9
평가   적정
```

## 16. 가이드 / 커스터마이징 화면

### 16.1 템플릿 탭 (고정 아님, 편집 가능)
```text
[등·어깨·이두] [가슴·삼두] [하체]  [＋ 템플릿]
```
- 탭 길게 눌러 이름 변경 / 삭제 / 순서 변경.

### 16.2 종목 편집
```text
랫풀다운
28kg · 8~12회 · 3세트 · 필수 · 워밍업 OFF
[수정]
```
편집 항목: 운동명 / 중량(미정 허용) / 세트 / 반복 범위 / 필수·선택 / 워밍업 ON·OFF / 순서 / 메모. 운동 추가·제거 가능.

### 16.3 요일 매핑 편집
```text
요일 배정
월 [ 없음 ▾ ]   화 [ 등·어깨·이두 ▾ ]   수 [ 없음 ▾ ]
목 [ 가슴·삼두 ▾ ]  금 [ 없음 ▾ ]  토 [ 하체 ▾ ]  일 [ 없음 ▾ ]
```
드롭다운으로 요일마다 템플릿 배정. 화목토 → 월수금 전환 등 자유.

## 17. AI 코치 화면
### 17.1 내보내기
```text
최근 기록·현재 가이드를 AI 분석용 문장으로 만듭니다.
[프롬프트 생성]  [복사]
```
### 17.2 가져오기
```text
AI가 반환한 Fitlog JSON을 붙여넣으세요.
[붙여넣기 영역]
[검증]
```
검증 후 diff:
```text
변경 제안
랫풀다운   28kg → 32kg
프론트 레이즈  3세트 → 2세트
[개별 선택] [선택 적용] [취소]
```

## 18. 설정 화면
- 타이머: 세트 휴식 90초 / 운동 간 휴식 180초
- 알림: `🎧 알림 사운드 테스트`
- 데이터: `운동기록 백업` / `백업 복원` / `전체 데이터 초기화`(강한 확인)
- 안내: 데이터가 기기에만 저장되므로 주기적 백업 권장 문구

## 19. UI 스타일 방향
단순 배경 / 얕은 카드 구분 / 명확한 텍스트 대비 / 상태 색은 보조로만 / 숫자·버튼 크게 / 손에 들고 보는 앱 / iPhone 세로 최우선 / 하단 Safe Area 고려.

금지: 그라데이션 남용 / 과도한 그림자 / 큰 일러스트 / 화려한 차트 / 불필요한 애니메이션 / 매 세트 모달 / 저장 토스트 남발.

## 20. 가장 중요한 사용자 플로우
```text
헬스장 도착 → AirPods 착용 → Fitlog 실행 → 🎧 알림 테스트
→ 오늘 템플릿 확인/선택 → 첫 운동 → 중량/반복 확인 → 세트 수행
→ 반복수 입력 → 완료 버튼 1회 → 90초(화면 유지) → 차임 → 다음 세트
→ 마지막 세트 완료 → 180초 → 다음 운동 → 웨이트 종료
→ 유산소 30분 입력 → 저장
```
이 플로우에 불필요한 화면 이동을 추가하지 않는다.
